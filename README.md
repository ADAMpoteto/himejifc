# 姫路FC 公式サイト

姫路市社会人サッカー2部リーグ所属「姫路FC」の公式サイトです。
https://adampoteto.github.io/himejifc/

データは Google スプレッドシート「姫路FC」から読み込みます。スプシを書き換えると、サイトにそのまま反映されます（ファイルの更新は不要）。書き方の詳しい説明は、スプシの「説明」シートにあります。

## ファイル
| ファイル | 中身 |
|---|---|
| index.html | ページの枠（ヘッダー・フッター） |
| app.js | ページの中身を作るプログラム。一番上の `SHEET_ID` がスプシのID |
| style.css | 見た目 |
| emblem.png・favicon.ico・icon-192.png・apple-touch-icon.png | エンブレムとアイコン |
| images/ | 写真・ロゴ（下の「画像」を参照） |
| demo/ | 確認用のダミーデータ（下の「ダミー表示」を参照） |

app.js・index.html・style.css を変えたときは、index.html の `?v=…` の数字も変えると、ブラウザに古いファイルが残りません。

## スプシのつなぎ方
スプシを「共有 → リンクを知っている全員（閲覧者）」にしておけば表示されます。
読み込みが不安定なときは、「ファイル → 共有 → ウェブに公開」したURLを app.js の `PUB_URL` に貼ってください。

## スプシのシート
| シート | 入れるもの |
|---|---|
| お知らせ | 自由なニュース（練習・練習試合・イベント・記録など）。画像は images/news/ に置いてファイル名を書く |
| 試合 | 1試合1行。A列の試合Noは日付から自動で入る。得点・失点が空欄の試合は「次の試合」になる |
| 出場選手 | 1試合×1選手。試合Noはプルダウン。得点・アシスト・MOM（チェック）はここだけに入れる。ポジションを「右SB・ボランチ・トップ下」などで選ぶと、スタメン図がその位置に並ぶ |
| 試合経過 | 何分にゴール・警告・交代があったか（試合ページの「経過」用。なくてもOK） |
| 選手・スタッフ | 選手もスタッフもここ。役職（監督・コーチ・主将・代表など）・前所属（期間はカッコ）・加入年・ID（URLと写真のファイル名） |
| 加入・退団 | 移籍のお知らせ。加入・退団ページとニュースに出る |
| チーム | 対戦相手のチーム名とロゴのファイル名 |
| SNS投稿 | トップに並べる Instagram・X の投稿URL |
| スポンサー | 区分「プラン」＝スポンサープラン、「パートナー」＝スポンサー企業 |
| シーズン | シーズンごとのリーグ・順位・カップ戦（「○○ 優勝」と書くと獲得タイトルに出る） |
| 順位表 | リーグの順位表 |
| 沿革 | クラブの歴史（年・出来事） |
| 過去の試合 | 2025年までの試合結果（対戦成績にだけ使う） |
| 設定 | クラブ名・練習場所・チーム理念・スポンサー料の使い道・募集状況・問い合わせメール・SNSのURLなど |
| 説明 | スプシの書き方（サイトでは使わない） |
| 選択肢（非表示） | プルダウンの中身を自動で作るシート。触らない |

## 試合結果の入れ方
1. https://adampoteto.github.io/himejifc/#input を開く
2. GoalNoteの試合ページの文字を全部コピーして貼り、「読み取る」
3. アシスト・MOM・ポジションを選ぶ
4. 出てきた3つの表を、それぞれ「試合」（B列）「出場選手」「試合経過」（A列）に貼る

## 画像
| 何 | 置き場所 | ファイル名 |
|---|---|---|
| 選手の写真 | images/player/ | 選手・スタッフシートのID（例：`utsumi-tomoaki.jpg`）。縦長（4:5くらい）がきれいに収まる |
| 相手クラブのロゴ | images/logo/ | 英数字（例：`kohdera.png`）。チームシートにファイル名を書く |
| スポンサーのロゴ | images/sponsor/ | 英数字。スポンサーシートの「ロゴ」にファイル名を書く |
| ニュースの画像 | images/news/ | 英数字。お知らせシートの「画像」にファイル名を書く |
| 自分のエンブレム | 一番上 | emblem.png |

- png / jpg / webp のどれでもOK。ファイル名に日本語は使わない（zipの解凍で文字化けするため）
- 画像がない選手・クラブは、名前の頭文字で表示されます

## お問い合わせフォーム
設定シートの「問い合わせメール」のアドレスに、#contact のフォームから届きます（FormSubmit という無料サービス）。
最初の1通だけ FormSubmit から「Activate」のメールが届くので、中のボタンを押してください。押すまでは届きません。

## ダミー表示（確認用）
URLの最後に `?demo` を付けると（https://adampoteto.github.io/himejifc/?demo ）、スプシではなく demo/ フォルダのダミーデータで表示します。新しい機能の見え方を確かめる用で、本番のデータには影響しません。
