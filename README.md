# 姫路FC 公式サイト

姫路市社会人サッカーリーグ所属「姫路FC」のサイト。データは Google スプレッドシート「姫路FC」から読み込みます。

## スプシのつなぎ方
スプシを「共有 → リンクを知っている全員（閲覧者）」にすれば、そのまま表示されます。
（読み込みが不安定なときは「ファイル → 共有 → ウェブに公開（ドキュメント全体）」して、そのURLを app.js の `PUB_URL` に貼る）

## スプシのシート
| シート | 1行に入れるもの |
|---|---|
| 試合 | 1試合。得点・失点を空欄にすると「次の試合（NEXT MATCH）」になる。得点者は「内海、土井（2）」のように書く |
| 出場選手 | 1試合×1選手の出場（先発・途中出場・ベンチ）・出場時間・得点・警告（2026年度から） |
| 試合経過 | ゴール・警告・交代の時間（交代は「選手」に入った選手、「関連する選手」に下がった選手） |
| 選手 | 名前・背番号・ポジション・生年月日・身長・前所属・メモ。背番号がある選手＝今年の登録選手 |
| シーズン | リーグ名・順位・市民大会／播州大会などの成績・主将・一言 |
| 順位表 | シーズン終了時の順位表 |
| 設定 | クラブ名・代表者・監督・コーチ・練習・ユニフォーム・Instagram などのURL |
| 説明 | スプシの書き方（サイトでは使わない） |

## 画像の置き方
| 何 | 置き場所 | ファイル名 |
|---|---|---|
| 選手の写真 | images/player/ | スプシの「名前」と同じ（例：`内海 友彰.png`） |
| 相手クラブのロゴ | images/logo/ | 試合シートの「相手」と同じ（例：`香寺SC.png`） |
| 自分のクラブのロゴ | images/logo/ | `姫路FC.png`（今は仮のエンブレム。本物に差し替えてください） |

- 拡張子は .png / .webp / .jpg のどれでもOK。
- 画像がない選手・クラブは、頭文字で表示されます。
- ファビコン（favicon.ico / icon-192.png / apple-touch-icon.png）も仮のエンブレムから作っています。

## 2026/10 デザイン更新で増えたもの
- 選手募集ページ（#join）：設定シートの「募集ポジション」「募集対象」「会費」「練習」などを表示
- スポンサー募集ページ（#sponsor）：スポンサーシートの「区分＝プラン」の行がプラン、「区分＝パートナー」の行がスポンサー企業として表示
- お問い合わせボタン：設定シートの「問い合わせURL」（Googleフォームなど）か「問い合わせメール」を入れると出ます
- スポンサーのロゴ：images/sponsor/ に英数字のファイル名で置き、スポンサーシートの「ロゴ」列にファイル名を書く
- ブラウザの「戻る」で、前のページのスクロール位置に戻るようにしました

## 2026/10 選手ページの更新
- 選手ページのURLは英数字になりました（例：#player/utsumi-tomoaki）。選手シートの「ID」列の値です。新しい選手を足すときは、ID（小文字の英字とハイフン）と英語名も入れてください
- 選手ページの「チームデビュー」「チーム初得点」「チーム初アシスト」は試合の記録から自動で出ます。記録より前の初出場などは、選手シートの「初出場」「初得点」「初アシスト」に文字で書くとそちらを表示します
- 昨シーズンまでの出場・得点は「シーズン記録」シート（シーズン・名前・出場・得点・アシスト）に入れると表に出ます

## ニュース・移籍・試合結果の入力
- 自由なニュース：「お知らせ」シートに 日付・カテゴリ（お知らせ／練習／練習試合／イベント／記録）・タイトル・本文・画像・リンク を1行書く。画像は images/news/ に置いてファイル名を書く（URLでもOK）
- 移籍：「加入・退団」シートに書くと、加入・退団ページとニュースに出ます
- 試合結果：サイトの #input ページ（例 https://adampoteto.github.io/himejifc/#input）にGoalNoteの試合ページの文字を貼る → 3つのシート用の行をコピーして貼るだけ
- SNS：設定シートの Instagram / X / YouTube にURLを入れると、ヘッダー・トップ・フッターに出ます

## お問い合わせフォーム
- 設定シートの「問い合わせメール」にアドレスを入れると、#contact のフォームが使えるようになります（FormSubmit という無料サービスで、そのアドレスにメールが届きます）
- 最初の1通目だけ、FormSubmit から「確認（Activate）」のメールが届くので、中のボタンを押してください。押すまでは届きません

## 試合レポート・SNS投稿
- 試合シートの「レポート」「監督コメント」「選手コメント（1行に1人「名前：コメント」）」に書くと、試合ページとニュースに出ます
- 「SNS投稿」シートにInstagramやXの投稿URLを書くと、トップページに新しい順で3件並びます
- 対戦成績は「過去の試合」シートと今の試合シートから自動で出ます
