# 姫路FC 公式サイト

姫路市社会人サッカーリーグ所属「姫路FC」のサイト。データは Google スプレッドシート「姫路FC」から読み込みます。

## スプシのつなぎ方
スプシを「共有 → リンクを知っている全員（閲覧者）」にすれば、そのまま表示されます。
（読み込みが不安定なときは「ファイル → 共有 → ウェブに公開（ドキュメント全体）」して、そのURLを app.js の `PUB_URL` に貼る）

## スプシのシート
| シート | 1行に入れるもの |
|---|---|
| 試合 | 1試合。得点・失点を空欄にすると「次の試合（NEXT MATCH）」になる。得点者は「内海、土井（2）」のように書く |
| 出場選手 | 1試合×1選手の出場（先発・途中出場・ベンチ）・出場時間・得点・警告（2026年度から） |
| 試合経過 | ゴール・警告・交代の時間（交代は「選手」に入った選手、「関連する選手」に下がった選手） |
| 選手 | 名前・背番号・ポジション・生年月日・身長・前所属・メモ。背番号がある選手＝今年の登録選手 |
| シーズン | リーグ名・順位・市民大会／播州大会などの成績・主将・一言 |
| 順位表 | シーズン終了時の順位表 |
| 設定 | クラブ名・代表者・監督・コーチ・練習・ユニフォーム・Instagram などのURL |
| 説明 | スプシの書き方（サイトでは使わない） |

## 画像の置き方
| 何 | 置き場所 | ファイル名 |
|---|---|---|
| 選手の写真 | images/player/ | スプシの「名前」と同じ（例：`内海 友彰.png`） |
| 相手クラブのロゴ | images/logo/ | 試合シートの「相手」と同じ（例：`香寺SC.png`） |
| 自分のクラブのロゴ | images/logo/ | `姫路FC.png`（今は仮のエンブレム。本物に差し替えてください） |

- 拡張子は .png / .webp / .jpg のどれでもOK。
- 画像がない選手・クラブは、頭文字で表示されます。
- ファビコン（favicon.ico / icon-192.png / apple-touch-icon.png）も仮のエンブレムから作っています。
